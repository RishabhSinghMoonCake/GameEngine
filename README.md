# 🛠️ Custom Game Engine (Work In Progress 🚧)

**An experimental game engine project exploring low-level systems, architecture design, and performance-focused development.**

---

## 🚧 Project Status

⚠️ **Work in Progress / Currently Paused**

This project was started as an attempt to build a **custom game engine from scratch**, focusing on understanding how core systems work under the hood.

While development is currently paused, the project reflects significant exploration into **engine architecture and system design**.

---

## 🎯 Vision

The goal of this project was to create a **modular and extensible game engine**, with full control over:

* Rendering pipeline
* Game loop & system orchestration
* Input handling
* Memory and performance management

---

## 🧠 What This Project Explores

* ⚙️ **Engine Architecture Design**
  Structuring systems like rendering, input, and core loop

* 🔄 **Game Loop Implementation**
  Managing updates, rendering cycles, and timing

* 🧩 **Modular System Design**
  Keeping components decoupled yet interoperable

* ⚡ **Performance-Oriented Thinking**
  Understanding low-level optimizations and constraints

---

* **Focus Areas:** Systems Programming, Game Engine Design
